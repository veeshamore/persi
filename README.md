# Content Creator Portfolio

A responsive personal portfolio for a content creator, built with semantic HTML, modern CSS, and lightweight JavaScript.

## Features

- Editorial, photography-led design
- Responsive desktop and mobile layouts
- Filterable project gallery
- Accessible mobile navigation
- Scroll reveal motion with reduced-motion support
- Contact form validation

## Run locally

Open `index.html` directly, or start a local server:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Customize

Replace the sample name, biography, statistics, client names, email address, and social links in `index.html` with your own details.
